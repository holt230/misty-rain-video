# 烟雨影视

个人云端影视片库与站内播放器，分别适配桌面导航与手机交互。支持资源检索与转存、片库更新、多用户目录隔离、播放历史、画质/音轨/字幕切换，以及安卓 PWA 和 iPhone Web Clip 桌面入口。

项目不提供、内置或销售影视内容，请仅管理和播放自己有权使用的资源。

## 主要功能

- 电视剧、电影、综艺和动漫统一片库
- 默认进入发现首页，浏览近期热播、电影、动漫与综艺海报，支持动漫每周放送；收藏与追更、观看记录分开导航
- 自动识别剧集、更新集数并过滤非视频文件
- 高清、超高清、4K、音轨与字幕切换
- 续播、片头片尾跳过和自动下一集
- 宣传海报匹配、多用户登录及独立目录
- 单容器部署，对外只开放一个端口
- 默认跟随系统颜色，可手动选择暗色或浅色并记住选择
- 删除影片时同步清理对应观看记录，包含旧格式记录

## 发现与播放

发现首页使用豆瓣当前榜单的影视元数据和海报，动漫另提供 [Bangumi 放送表](https://bgm.tv/calendar)。不需要额外 API Key。点击海报先进入独立影片详情页，主动点击“搜索资源”后才开始网盘检索；打开资源后点击视频播放，勾选文件或目录收藏，也可收藏全部。收藏与观看记录仍可直接播放，直接观看后再保存不会产生重复的观看记录。

推荐数据默认每 6 小时刷新，成功结果持久化到 `data/discovery-cache.json`；来源异常时保留上次推荐并显示更新时间。海报通过服务端按需缓存，限制并发、超时、图片大小和来源域名。榜单元数据不代表网盘资源一定可用，分享链接仍经过现有的有效性校验。

`GET /api/discovery?category=all` 返回分类推荐；分类支持 `all`、`tv`、`movie`、`anime`、`variety`。推荐和海报接口均需要登录，点击海报时保留元数据身份、分类、年份和封面，手动改搜其他片名会清除原条目的关联。

发现页直接展示推荐内容，分区标题及列表末尾提供对应片库入口。片库将电视剧、电影、动漫、综艺与类型、地区、年份筛选统一展示，默认按热门排序，可切换最新或评分；筛选行默认单排，支持展开。首页轮播每 3 秒切换，首次随机起点，鼠标悬停暂停，进度指示随当前位置滚动。

网盘搜源支持部分片名、空格标点和 `第二季 / S02` 等写法，并按相关性排序；明确不同季的资源仍会被排除，自动维护继续使用严格身份校验。豆瓣片名搜索合并精选结果、普通结果和网页搜索建议，按条目 ID 去重；接口受限时明确提示部分结果。

## 影片详情

详情页展示公开可取得的简介、评分与评价人数、演职员、类型、地区、语言、上映日期、片长、集数、别名及 IMDb 编号，并合并补充信息页中的编剧与主演资料。演职员名单和照片仍受上游公开接口返回范围限制，不保证完整。

演职员和剧照默认单行，支持左右滚动。剧照在站内预览并按需加载，每页 24 张；大图支持前后切换、手机滑动、Escape 和浏览器返回。短评每页 20 条，按需继续加载；仅页脚保留资料来源链接。浏览详情和补充资料不会触发网盘检索、转存或播放。

详情最多持久缓存 100 部影片，分页资料最多 120 页，默认复用 6 小时；上游异常时最多保留 7 天旧资料并明确标记。详情与分页请求分别限制并发和超时，重复请求合并，失败短期退避；图片只接受允许的官方域名。缓存保存在 `data/catalog-details.json` 与 `data/catalog-detail-content.json`，不涉及网盘视频清理。

## 资源浏览与收藏

搜源结果采用紧凑列表，点击来源后按文件夹浏览。文件行展示网盘实际提供的缩略图、文件名、大小和修改时间；没有缩略图时显示文件图标。单层包装目录会自动进入，面包屑可返回上级；支持按名称、大小或时间排序。点击视频播放该确切文件，勾选视频或文件夹后收藏，也可收藏全部。确认没有视频的资源会从候选中移除，匹配字幕仍随视频保留。

缩略图按需加载，通过已登录用户的短期地址代理；不向前端暴露签名地址。每张图最多2MB、8秒超时、最多3路并发，服务器图片缓存上限8MB。搜索结果尚未读取目录时，不编造文件大小或缩略图。

“收藏 / 追更”保留已保存资源与自动维护能力；“观看记录”提供日常续播，设置页不再重复展示历史。名称和入口调整不移动已有网盘目录、不修改文件留存策略。移除收藏仍会把对应影片目录放入云盘回收站，并清理相应观看记录，操作前会确认。

## 搜索与播放页

顶部按片名搜索时先展示豆瓣影片卡片，包含年份、类型和季数等信息；点击卡片进入影片详情，再通过“搜索资源”检索网盘资源。没有收录、未找到目标或豆瓣接口暂不可用时，可主动选择“直接搜索资源”。已缓存的豆瓣当前榜单也会补充同名条目，避免新一季只在榜单里出现。分享链接仍可直接粘贴添加。

播放使用独立页面，支持浏览器返回、前进和当前标签页刷新续播；地址使用不包含分享链接或提取码的临时标识。换设备或清除标签页状态后，应从片库或观看记录重新打开。新剧从最早可用的一集开始，看过的按记录续播；自动下一集只连接同季的连续集数，电影不会自动播放另一个版本。

### 按需播放文件的留存

直接播放会把所需视频及匹配字幕保存在该用户的 `_临时播放` 目录，目前**没有自动删除期限**；两小时过期的是闲置播放会话，网盘文件不会因此删除，空间会随观看累积。原分享明确取消后，仍可播放这个用户已缓存的文件；未缓存的集数需通过“换源”查找，缓存播放不会跳过缺集或自动选择不确定的片源。

自动补集和失效来源重连仅适用于已保存到片库、能核对片名/年份/季数/集数的剧集，不包含临时播放，也不保证尚未发布的下一集能够找到。收藏时选择“全部保存”可进入片库维护；已有文件会保留。

## 分享链接校验

搜索候选会申请分享令牌并检查目录内容，确认至少有一个可访问的视频后才标记可用。每次探测总计最多6秒、单请求最多3秒，最多检查8个目录、每目录4页；找到视频后提前结束，不下载或转存视频。服务端最多4条并发、32条待处理，客户端批量校验最多等待30秒。

确认取消、过期或不存在的分享排除30分钟；完整检查后没有视频的分享排除5分钟。目录读取不完整、网络错误或超时暂缓30秒，之后允许重新检查；提取码和认证故障不作为永久失效依据。有效结果复用1分钟，缓存跨重启保留并自动过期。

打开详情或换源时发现不可用，会移除当前候选；晚到的预取结果或刷新不会把本轮已失败的按钮重新加入。缺少当前集只影响当前影片的换源，不全局封禁分享；失败时保留正在播放的视频和进度。

资源详情和播放共用完整分页读取，使用夸克实际支持的 `_page/_size` 参数并核对提供方返回的总数。重复页或提前空页会明确报错，不把部分目录当作全部集数。播放列表按真实文件标识保留视频，同集编号的不同版本、无编号视频和花絮均可手动选择；默认播放与自动连播优先正片。转存和自动追更仍采用独立的正片选择规则。

## 字幕与播放偏好

播放器控制栏基于西瓜播放器（xgplayer），复用原生视频元素和已有网盘直连链路；进度、音量、画中画和触摸交互由播放器处理。iPhone 系统全屏继续使用原生字幕轨道，业务层负责片源、转存、续播与账户偏好。

播放设置提供统一的字幕开关与语言选择，默认自动优先中文；手动关闭或选定语言后会记住当前账户在此浏览器的选择。支持浏览器/HLS字幕轨道，以及影片同目录或字幕目录中的VTT、SRT、ASS、SSA文件。ASS/SSA按文本字幕呈现，外部字幕文件最大2MB，支持UTF-8、UTF-16及GBK编码。

对于网盘MP4转码流中的tx3g文本字幕，服务器自动按播放时间读取并通过标准HTML字幕轨道交给浏览器显示，修正源轨道的右对齐定位，拖动进度后自动加载对应字幕。所选轨道带有Safari所需的默认轨道标记；分段加载只补充文本，不修改开关状态。原生全屏使用系统底部排版，网络读取暂时失败时会有限次自动重试。仅读取MP4索引和字幕数据，视频仍按原有方式直连；索引上限12MB，每90秒字幕窗口上限1MB，最多2个任务并发。原始MKV、图形字幕、加密或特殊分片格式仍取决于浏览器或网盘转码支持，不会为获取字幕下载或转码整部影片。

选集保存时会保留匹配的字幕文件，选择文件夹或全部保存时按正片存储规则保存影片及匹配字幕。SUB/IDX等文件也会随匹配视频保存，当前播放器支持上述文本格式。

片头和片尾时长可分别配置为0～600秒，0表示不跳过该部分。跳过与连续播放偏好按账户保存；自动跳过会保留超过60秒的正片内容。主题和字幕语言选择在当前浏览器保存。主题只在设置页提供；认证与自动维护位于管理员专属的“高级配置”。

播放器控制栏保留播放／暂停、时间与进度、倍速与画质快捷入口、播放设置和全屏；桌面端保留音量，全屏时另有选集入口。快捷入口固定宽度，画质名称在下拉选项中完整显示，只有一种画质时隐藏快捷入口。画质、倍速、字幕及适应／铺满／裁切（125%）也可在“播放设置”的紧凑列表中调整，画面调整不重置进度。音轨仅在可切换时出现，画中画仅在设备支持时出现；跳片头片尾、连续播放和弹幕默认折叠在“播放偏好”中。设置面板跟随深浅主题，手机上使用底部面板，内容过多时在面板内滚动。

播放器下方展示片源与选集；选集提供缩略图列表、无图紧凑列表、数字格三种视图，并记住正序／倒序和视图偏好。仅提供“收藏整部”。桌面播放器与选集并排，手机上下排列；全屏时同一个选集面板进入菜单，退出后恢复。换源先确认同季同集存在并保留进度，不跳过缺失集数。收藏不打断播放，选集按文件或剧集名称展示，不把年份当集数。

播放中控制栏可自动隐藏，轻触画面即可唤出并暂停。网页播放区保持16:9，铺满按容器裁边，裁切进一步放大125%。iPhone全屏使用系统原生播放器，缩放与字幕显示由系统接管；桌面与安卓优先请求整个播放器的真实全屏，保留网页字幕和控件，安卓在设备支持时锁定横屏。不支持或拒绝全屏时保留当前页面并提示，不用网页旋转模拟。

后台备选片源只读取分享信息，不转存或预加载视频；每次最多检查12个候选，展示最多5个可用源，20秒后取消，退出播放页时中止请求。服务端为后台检索限制并发，优先保障手动搜索；共享检索任务有30秒上限。检索结果持久保留最多120个关键词，5分钟内复用，过期结果最多保留12小时并在访问时清理。此清理只针对元数据缓存，不删除收藏或临时播放文件。

同一会话/文件的重复播放准备请求共用一次取流；收藏和历史读取合并并发请求，晚到的旧响应不会覆盖保存/删除后的状态。删除收藏不再额外遍历全量网盘，删除历史不重新抓取全部海报。

剧集缩略图来自网盘文件元数据，通过当前账号的播放会话鉴权后读取；不会额外遍历目录或下载视频生成缩略图。仅缩略图视图创建图片请求，紧凑列表和数字格不加载图片。未提供图片时显示视频图标。菜单、片源栏和选集均适配系统浅色/暗色主题。

### 安卓 Chrome / PWA 播放

安卓浏览器与安装后的 PWA 共用同一播放器。在“设置 → 安装到桌面”调用浏览器安装提示；浏览器未提供提示时，使用 Chrome 菜单中的“添加到主屏幕”或“安装应用”。部署需使用 HTTPS；安装后的 PWA 仍需联网播放，不缓存整部影片。

播放时左右双击画面后退／快进10秒；倍速和画质支持控制栏快捷调整，字幕和画中画从播放设置进入，全屏时保留快速选集入口。桌面与安卓文本字幕统一居中放在实际画面底部，全屏控制栏显示时避开控件。选择“字幕关闭”后不会额外渲染字幕；进入浏览器原生视频全屏或画中画时由浏览器接管字幕，具体支持取决于设备。

支持的设备会在前台播放时申请保持亮屏，暂停、切到后台或退出时释放；系统可能因省电等策略拒绝亮屏请求。系统媒体面板可播放/暂停、跳转进度，存在同季连续下一集时可切集。普通后台切换暂停播放，画中画除外；关闭后台画中画也会暂停。返回页面后轻触即可续播。PWA 沿用浏览器解码能力，不能额外保证 MKV、图形字幕或特殊音视频编码的兼容性。

## 站点设置

管理员可在“设置 → 站点设置”修改站点名称、副标题、简介和图标，普通用户不显示此入口且不能调用修改接口。支持上传 5 MB 以内的 PNG、JPG、WebP 图片，并自动生成浏览器与桌面安装所需图标；可恢复默认后保存。

保存后当前页面立即更新，其他页面刷新后读取最新信息。配置持久保存在 `data/site-settings.json`，重启和更新镜像后保留；名称修改只影响站点展示与安装信息，不重命名网盘目录或账号。已安装的桌面应用名称和图标由浏览器／系统管理，可能需要重新安装才会更新。

## 弹幕关联

弹幕支持腾讯、爱奇艺、优酷和 B 站来源。明确匹配的作品可自动加载；作品版本或季度有歧义时，先确认作品与当前集数，再选择本季沿用或仅本集。确认前浏览候选不会替换正在显示的弹幕。已确认的来源和分集对应按账户保存，换集、主动换片源和恢复播放历史时继续沿用；缺集或连接失败保留关联，不自动换到同名作品。

B 站番剧链接可关联作品目录，独立视频链接仅关联本集。分段文件需要单独确认。工具栏提供海量、少量和关闭三个档位，设置中可调整显示区域、字号、不透明度和时间偏移。iPhone 网页全屏保留弹幕；系统视频全屏由浏览器接管，不显示网页弹幕。清理分段缓存不会删除用户确认过的关联。

## Docker Compose 部署

要求：Linux x86_64、Docker Engine 24+、Docker Compose v2。镜像由 holt230/misty-rain-video 的 main 分支构建发布。

```text
ghcr.io/holt230/misty-rain-video:amd64
```

下载仓库中的 `docker-compose.yml` 后执行：

```bash
docker compose pull
docker compose up -d
docker compose ps
curl http://127.0.0.1:5200/api/health
```

访问 `http://服务器IP:5200`。默认示例账号为 `admin / 666666`，正式开放前必须修改 `docker-compose.yml` 中的密码。

管理员首次登录后，在“设置 → 高级配置 → 网盘认证”中提交已登录网盘网页的 Cookie，再执行片库更新。

视频强制网盘直连，需在“设置 → 高级配置”完成 TV 播放认证。认证不可用时明确提示，不回退网页 Cookie 中转；旧的中转偏好、查询参数或环境变量也不能重新启用视频代理。设备兼容性、验证边界、认证服务依赖和部署步骤见 [网盘直连播放](docs/direct-playback.md)。

### 可选环境变量

在 `docker-compose.yml` 同目录创建 `.env`：

```env
IMAGE_NAME=ghcr.io/holt230/misty-rain-video
IMAGE_TAG=amd64
TZ=Asia/Shanghai
APP_PUBLIC_URL=https://example.com/misty-rain/
QUARK_CONFIG_SECRET=
```

- `APP_PUBLIC_URL`：配置域名时填写完整 HTTPS 地址。
- `QUARK_CONFIG_SECRET`：可在首次认证前设置固定加密密钥；已有数据时不要随意修改。

### 多用户

用户在 `docker-compose.yml` 的 `APP_USERS_JSON` 中配置：

```yaml
APP_USERS_JSON: >-
  [
    {"username":"admin","password":"请修改密码","role":"admin","folder":"admin"},
    {"username":"family","password":"请修改密码","role":"user","folder":"family"}
  ]
```

`folder` 是用户在网盘片库中的稳定目录名。管理员可以维护播放认证，普通用户无法查看或修改认证信息。

## 数据持久化

Compose 使用唯一命名卷 `misty-rain-video-data` 持久化 `/app/data`，其中包含：

- 加密后的播放认证和密钥
- 用户片库设置及播放历史

### 正片存储与自动追更

新入库、手动换源和补集均递归识别正片，只转存视频文件到影片目录，不再复制原分享目录、图片、说明文档和可识别的花絮。识别到集数时使用 `第01集.mkv` 命名，有季数/分段时使用 `第02季 第01集（上）.mkv`，保留真实扩展名。不确定集数的文件保留原名。历史嵌套目录仍可读取，不自动整理或删除；重命名失败时已存视频保留原名。

生产服务启动约 1 分钟后开始后台维护，默认每轮间隔 30 分钟，每位用户每轮最多检查 20 部到期影片。使用原片源补充缺集，不替换已保存的同集视频。连续 3 次确认来源不可用后才搜索候选，每位用户每轮最多检索 2 部影片、每部验证 5 个候选；下一轮继续后续候选，不反复限定最前 5 条。网络错误、风控、认证失败不会触发换源，临时故障逐步退避，最长间隔 6 小时。来源已确认不可用后仍按正常间隔发现候选，候选检索失败不清除原来源的失效记录。检查进度保存在持久化数据卷中，关闭网页或重启服务不会丢失。

夸克在分享令牌或目录接口用 HTTP 400、404、410、422 明确返回“好友已取消了分享”等信息时，计入来源不可用；未知 HTTP 错误、限流、提取码问题和认证失败仍按临时故障处理。升级这项错误分类修复后，旧的异常记录在首次巡检重新检查，不沿用错误分类造成的长时间退避。“自动追更”会显示确认次数、每部影片的检查时间及下次自动复查时间。

自动关联要求能核对片名、已知年份、季数和已有剧集覆盖情况；有歧义的合集、无法识别集数的内容和电影不自动换源。关联只更新后台来源记录，保留影片目录 FID、已存视频、收藏和观看记录。已有电影也不会自动保存其他画质版本。上游未更新、来源无法确认或认证失效时，不能保证即时更新；“我的 → 播放与片库 → 自动追更”可查看具体状态。

仅对有精确目录 FID 元数据的片库条目执行自动维护，避免按同名标题错配历史目录。`pnpm dev` 不启动维护；生产 `node server.js` 启动。环境变量：

使用详情页选择部分剧集或文件夹时，也只平铺保存选中范围内的正片；后续补集遵守该范围。若这类来源失效，由于新分享的文件标识不同，后台保留选择范围等待恢复，不会自动换成“保存全部”。

- `LIBRARY_AUTO_MAINTENANCE=false`：关闭后台自动维护，保留手动操作。
- `LIBRARY_MAINTENANCE_MINUTES=30`：轮次间隔（15～1440 分钟）。

依赖有效的网盘 Cookie、可用的资源检索服务和足够的网盘空间，不需要追加 TV 扫码授权。转存由网盘内部完成，不把视频下载到应用服务器。多副本部署时只能在一个实例开启维护，同一网盘也不要同时启动多个维护服务；目录互斥锁仅保护单进程。更新镜像并重建容器后生效，保留 `misty-rain-video-data` 卷。

## 更新与日志

搜索默认并行请求内置引擎的插件和频道通道，先展示已返回的候选，再自动补充其余结果。首批结果/进度默认最多等待 8 秒（`RESOURCE_SEARCH_TIMEOUT_MS`），后台任务最多运行 30 秒，慢来源不会因为首屏已返回而被取消。内置引擎正常响应后，在约 5 秒、15 秒各读取一次其已补齐的缓存（受整轮 30 秒限制），新增候选会自动出现在页面。服务器查询失败、为空或仅取得部分结果时，恢复浏览器请求既有公共备用源的路径：不阻塞已有候选，按分享链接合并结果，服务器后续响应不能覆盖补充结果。浏览器与服务器的网络出口不同，这条路径用于补充服务器无法访问的索引，不要求生产直接访问 Telegram。

浏览器补查最多等待 10 秒，同关键词请求合并，成功结果复用 5 分钟，失败后至少等待 30 秒再尝试；不会发送本站 Cookie、认证头或 Referer，本站登录失效时不补查。备用源仍须对用户网络可达并允许跨域访问，不能保证任何时候都返回固定数量。

首批结果、服务器缓存补齐和浏览器备用结果统一按片名边界过滤。例如搜索“仙逆”会保留年番、剧场版和不同画质的相关版本，剔除因“剑仙逆世”“修仙逆袭记”等字样被上游误收的其他作品；支持片名中的空格、标点和不可见字符，不按任意位置的连续两字判断相关性。推荐、最新、4K 和完整列表均排除明确标注的沙雕版、解说和混剪内容；保存分类为动漫时不混入同名短剧。添加资源时仍会读取分享内的视频文件验证链接。

内置引擎固定为官方 2026-10-12 的 amd64 镜像，源码版本 `221665fb2c9279f22af4684ea2d8c0c331eac1cc`，使用不可变镜像摘要（见 `Dockerfile`）。不再使用停留在 5 月的 `search-amd64` 镜像。默认启用 `erxiaopan`、`wanou`、`quarktv`、`quark4k`、`quarksoo`、`pansearch`、`hunhepan`；移除新引擎已不注册的 `qupanshe`、`qupansou`、`hdr4k`、`jikepan`，防止配置存在但实际未加载。显式配置 `RESOURCE_SEARCH_PLUGINS` 时以管理员配置为准，需要将 `erxiaopan` 加入列表。

镜像构建会在生产运行环境中执行 `scripts/verify-search-runtime.mjs`，只验证启动和插件注册，不搜索或操作网盘；未加载 `erxiaopan` 或配置中的插件时不发布镜像。启动日志也会列出实际加载的插件及缺失项。新引擎使用 `data/search-cache-v2`，保留旧缓存目录方便回滚；应用的旧搜索缓存会重新核对，不需要删除整个数据卷。新来源是否能从生产服务器访问仍取决于站点和网络。

“重新搜索”先读取内置引擎已经补齐的结果，再传递 `refresh=true` 刷新并合并；不会因为重跑时只返回较快的插件结果，就丢掉已找到的正篇。后续补查不强制刷新，以便读取异步完成的结果。后台自动维护等待本轮检索结束后再选择来源。

内置引擎只通过容器内回环地址通信，禁用其响应压缩，并发送 `Accept-Encoding: identity`，避开部分 PanSou 版本压缩中间件重复写正文导致的 JSON 解析错误（如 `Unexpected non-whitespace character after JSON`）。外部来源和网站对外压缩不受影响；不会截取损坏响应中的第一段 JSON 冒充完整结果。

成功检索缓存保存在数据卷的 `resource_search_cache.json`，新鲜结果复用 5 分钟，12 小时内旧结果可先展示并后台刷新；界面会说明缓存或部分结果状态，转存时仍验证分享。空结果只短暂缓存 10 秒。自动追更检索保留严格刷新策略，并为手动搜索预留并发容量。检索仍依赖上游可达性，不能保证新关键词在所有来源故障时返回结果。

## 本地开发

### 本机运行与临时外网访问

本地部署使用 Node.js，绑定 `127.0.0.1:5200`，通过 Cloudflare Quick Tunnel 提供临时 HTTPS 地址。适合先验证本人和家人的访问线路；临时服务没有可用性保证，重启后地址会变化，不作为长期视频分发方案。

首次准备需要安装依赖、构建前端，并将对应操作系统和架构的官方 `cloudflared` 可执行文件放入 `.local-runtime/cloudflared`。当前 Apple Silicon Mac 可执行：

```bash
pnpm install --frozen-lockfile
pnpm build
mkdir -p .local-runtime
curl -fL https://github.com/cloudflare/cloudflared/releases/download/2026.8.3/cloudflared-darwin-arm64.tgz -o .local-runtime/cloudflared.tgz
tar -xzf .local-runtime/cloudflared.tgz -C .local-runtime
./start-local.sh start
```

日常管理不会重复构建：

```bash
./start-local.sh start   # 后台启动；已运行时显示现有地址
./start-local.sh status  # 查看本地和临时外网地址
./start-local.sh stop   # 停止本地服务和穿透进程
```

环境配置和运行日志统一保存在项目的 `.local-runtime/` 目录。首次启动自动在 `.local-runtime/.env.local` 创建 `admin` 账号和随机密码，文件权限为仅当前用户可读写；修改密码后停止再启动。登录后需由管理员在“设置 → 高级配置”配置网盘 Cookie 和 TV 播放认证。本地 `data/` 与服务器数据独立，不会自动迁移。原生部署没有 Docker 镜像中的内置检索引擎，检索依赖远端备用源。

运行日志位于 `.local-runtime/service.log`，临时地址位于 `.local-runtime/public-url.txt`。整个 `.local-runtime/` 目录均不提交到 Git，也不进入 Docker 构建上下文。脚本不配置开机自启或防休眠；电脑需保持开机联网且不休眠。当前脚本面向 macOS/Linux，不支持 Windows 原生运行。
