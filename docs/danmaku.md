# 弹幕

开启播放器下方的“弹幕”开关后，服务会根据片名、年份、分类与季度自动查找作品，再用真实集号定位剧集。普通使用不需要选择平台或填写链接；首次开启默认使用少量弹幕，弹幕数量和清晰程度会保存在当前浏览器。

精确且唯一的作品会自动关联；同名、年份或季度有歧义时，主界面只提示“选一下片名”，用户选择一次即可记住，平台由服务自动选择有本集数据的来源。目录缺少对应集数时不会按列表位置猜集数。需要手动处理时，可在“弹幕设置 > 更多选项”中粘贴本期腾讯、爱奇艺或优酷的具体播放链接，或调整来源和时间校准。手动作品关联按登录用户保存，并用于后续剧集；直接链接只关联当前集。

换集时先使用已确认作品和上次成功的平台；该平台缺少本集链接或无法解析时，会在同一作品内尝试其他支持的平台，不会自动换成同名作品。全部尝试失败时保留原关联：目录确实缺少本集时提示“本集暂未收录弹幕”，来源连接或解析失败时提示“弹幕来源连接失败，请重试”。重试会重复刚才的作品选择、片名搜索或链接关联，不需要重新填写。这个回退发生在剧集定位阶段，不代表已选来源的弹幕分段请求失败时会自动切换平台。

## 数据源与运行

- 腾讯：按 30 秒分段读取；爱奇艺：按 300 秒分段读取并解析 zlib/XML；优酷：按 60 秒分段读取，由后端获取匿名临时 Cookie 并完成签名。
- 优酷兼容 `/video?vid=…` 新链接和 `/v_show/id_….html` 旧链接，按链接中的真实剧集编号定位。
- 不要求提供会员账号或登录 Cookie。优酷匿名令牌只保留在内存中，令牌过期最多刷新一次；权限限制和不支持的新格式会作为不可用状态处理。
- 作品及剧集目录使用 360 影视搜索与详情接口。目录不可用时仍可粘贴三平台具体剧集链接。
- 弹幕适配在现有 Node 后端运行，不需要单独部署服务；应用 API 沿用登录验证和写入请求的同源校验。
- 共享分段缓存：`data/danmaku/segments/`，有效期 10 分钟，上限 256 个文件 / 64 MiB，写入时清理超过 24 小时的缓存。
- 用户关联：`data/danmaku/users/<用户散列>/<影片散列>.json`。配置文件与日志仍沿用项目的 `.local-runtime/` 目录。
- 分段请求失败后，自动加载退避 30 秒；手动“重试”和“刷新弹幕”会绕过退避与缓存，重新请求平台，同时保留并发合并和 API 频率限制。失败仍有缓存时继续显示旧弹幕，并提示“弹幕更新失败，正在显示缓存”；没有缓存时提示“弹幕暂时没加载出来”。不会影响视频播放。来源、获取时间和详细错误默认收在高级设置中。
- 播放时按需加载当前段并预加载下一段，前端只保留附近少量分段。关闭弹幕或切集会取消旧请求、销毁渲染器。

接口没有官方稳定性承诺，也没有验证取得平台的数据再分发授权；不要将可调用理解为官方开放授权。返回数据可能经过筛选、限量或缓存，界面“获取于”表示本服务成功获取的时间，不承诺全量、实时或所有影片覆盖。

## 播放器行为

使用 MIT 许可的 `danmaku` 组件，以原生视频时钟驱动普通网页弹幕，支持暂停、拖动、倍速和容器尺寸变化。默认在画面上部显示，每两秒最多一条（适中为两条），避免大量弹幕挤占手机资源。所有内容以纯文本显示，不执行弹幕中的 HTML。

手机旋转到横屏后自动进入网页内沉浸播放，视频和滚动弹幕共同铺满可用画面。手机播放条使用播放/暂停、进度、静音、影片字幕（有字幕时）和一个横屏切换图标；播放时自动淡出，轻触画面可唤回。桌面继续使用原生控制条。

点击播放条右侧的横屏图标，可在竖排锁定时将整个网页播放区域旋转 90 度，视频、弹幕与操作条一起旋转，不请求设备方向锁定，也不进入 iPhone 系统视频全屏。再次点击同一位置退出横屏；在设备横放时退出，不会因浏览器地址栏伸缩又自动进入。横屏下保留关闭播放器入口，其他播放设置和选集在退出横屏后操作。画面继续遵循原有适应/填充设置，默认保持比例。

已移除字幕式弹幕和动态弹幕字幕轨，飘屏继续使用现有 `danmaku` 渲染器。浏览器地址栏可能仍然显示，网页不能保证获得原生 App 的完整物理屏幕。通过浏览器外部入口进入系统视频全屏时，网页弹幕仍无法覆盖系统播放器。

真机验收仍需检查：iPhone 16 Pro 开启/关闭竖排锁定后的网页横屏、横竖切换和地址栏伸缩、旋转后的进度拖动、暂停/续播、字幕选择、跨片段弹幕同步，以及退出/切集后的布局恢复。自动化测试不代表这些 Safari 真机交互已验证。

## 验证与更新

```sh
pnpm test:danmaku
pnpm exec vue-tsc -b
```

测试包含平台响应解析、新旧优酷链接、匿名令牌刷新、真实集号、匹配歧义、来源故障与缺集区分、记忆作品的平台回退、缓存过期与失败回退、用户隔离、API 认证，以及组件开关、拖动、迟到响应、切集清理、全屏事件和保留原操作的手动重试。组件测试采用 JSDOM，不代表 iPhone 真机验证。

更新依赖和前端构建后，需要重启现有 Node 服务。使用本地启动脚本时：先执行 `./start-local.sh stop`，再执行 `./start-local.sh start`；临时穿透地址可能变化，通过 `./start-local.sh status` 查看。Docker 部署则使用更新后的镜像。
