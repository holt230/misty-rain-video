# 四平台首页片单

本次基于 main-master 的 b41663d，在 codex/official-platform-home 实现。

## 数据分工

- 首页：腾讯视频、芒果TV、优酷、爱奇艺各自的公开网页/网页数据请求；不以豆瓣热门列表替代失败的平台。
- 详情：平台片单中的简介与演职人员；需要补充时先按平台作品 ID 取得年份，再精确关联同名、同年、同类型的豆瓣资料。匹配有歧义时不关联。
- 短评：仅使用已确认对应版本的豆瓣短评，不能确认时显示原因；不制造评论。
- 官方进度：已有首页作品可凭对应平台 ID 直接核对正片目录；其他作品仍可通过现有作品搜索定位。更新集数不取首页宣传数字。
- 片源：仍由原搜索、实际视频文件核对、夸克入库和播放器负责。页面上有推荐作品不代表网盘已找到视频。

## 交互

首页保留影视分类，增加平台筛选。手机筛选以一行文字显示“全部、腾讯、芒果、优酷、爱奇艺”，五项完整显示，行高36px；不使用多层胶囊或单项截断。手机顶栏只保留品牌、搜索和历史入口，搜索按钮触发原找片页并聚焦输入框。电脑仍使用完整搜索框。找片页去除口号和常驻长说明，采用52px搜索栏、36px分类文字筛选；指定集说明只在输入了集数后显示。热门推荐随分类过滤，分享链接保存仍要求明确分类。

封面卡片标注播出平台；同一作品多个来源合并。不同明确年份或季数分别保留，未知年份只在已知版本唯一时归组。保存关联保留平台 ID 别名及原豆瓣 ID，不改动原网盘目录、FID 或观看历史。未确认版本时已有同名片库作为用户明确选择的播放入口。

横版图优先用于轮播，竖版图用于卡片；缺图时沿用已有占位图处理。资料和评论来源单独标注，不把平台评分或热度当作豆瓣评分。

## API与缓存

- GET /api/catalog?channel=tv|movie|anime|variety|new&platform=all|qq|mango|youku|iqiyi&page=1..50&revision=...
- 原数字作品详情/海报地址保持兼容；新作品使用编码后的 work:... 标识。
- 平台×分类快照位于 data/catalog/official/，作品索引在其 works/ 中。
- 每个平台快照有效1小时，读取过期快照时后台刷新并标注状态；失败至少间隔1分钟重试。生产启动5秒后按分类预热，每小时检查。
- 单平台筛选只查询该平台。四平台聚合各自获取并标记成功、过期或不可用；首次无快照失败与正常空片单分开显示。
- 每页最多24部，页数只覆盖已取得的公开片单范围，不宣称包含平台完整片库；后续页版本变化返回409。
- 新片列表只包含公开片单中上映日期可确认、近180天且已上映的电影。当前腾讯/芒果/优酷片单普遍缺该字段，因此可能在该筛选下为空，不拿其他平台条目顶替。

服务端最多同时3个片单请求，单次8秒，响应上限4MiB；使用匿名请求标识，不带用户或网盘凭据。腾讯、优酷的页面自带数据用 AST 的受限字面量解释器读取，不运行远程脚本。图片只能来自已登记平台素材域名，禁止跳转、限制大小并核对JPEG/PNG/WebP类型与文件头。

## 实际验证与边界

2026-11-17 本机直接访问真实公开数据，四个平台的电视剧、电影、动漫和综艺共16个入口均返回可识别作品。另验证了腾讯、芒果、优酷选中电视剧的官方年份资料；爱奇艺列表直接带有年份和演员。

隔离本地预览使用真实片单/海报/详情/评论，未使用假片单；片库使用独立空测试环境。浏览器验证手机320px、390px与默认电脑尺寸，平台筛选、快速切换、无横向溢出及顶部搜索聚焦正常。选中《多喜一家人》后真实关联2026年资料，展示简介、24位演职人员和短评。截图在忽略的 .local-runtime/official-home-*.jpg 和 .local-runtime/official-search-mobile.jpg。

定向回归84项通过，找片重排后指定集/分类/分享保存回归4项通过；Vue类型检查及git diff --check通过。未执行本机完整生产构建，也未提交或发布本次改动。

这次验证不代表已在 linlunji.cn 部署，也不替代新版本生产网盘入库和播放验收。测试不重复转存真实账户内容。公开页面/接口可能改版，版本、频道路径与数据结构需维护。

## 部署

前后端均需更新；Docker 发布新镜像后重建应用容器并保留原数据卷。不需要新增API密钥、代理、付费服务或重装iPhone描述文件。网络需要能连接各平台官网及上述图片域名。商业复用仍应核查平台条款和素材权利。

只读检查：
- node scripts/verify-official-catalog.mjs
- node scripts/verify-official-catalog.mjs --channel=tv --metadata

脚本不登录、不转存、不播放，只输出来源成功/失败、数量、耗时和少量作品字段。镜像中包含同一脚本。
