# 搜索实网验收

修改作品匹配、搜索来源或入库预览后，在已登录的测试环境使用真实索引与已认证的夸克网盘。先验收用户报错的片名，再从首页电视剧、电影、动漫、综艺各随机选两部。不要以单元测试、索引标题、来源标注的集数或 HTTP 200 代替页面验收。

1. 从首页或找片页输入片名与分类，等到结果显示。同一个报错片名重搜一次。记录返回了多少分享、每条是否失效，以及页面实际认可的文件和集数。
2. 如果索引有结果但页面没有，核对分享标题、实际各级目录、文件类型、集号和季度。确保同一剧的画质目录、过期更新标记不会误伤，也不要选进旧季、花絮、图片或伪装扩展名的文件。
3. 电视剧点「检查可存集数」，将已有、可补和缺少的集数与同一版本的官方正片进度对照。非连续集不要算完整；压缩包显示为待解压资源，不等同于已验证能播放。只读验收到预览为止。
4. 对空结果，使用独立的公开索引对照。要确认外站有资源，需打开它的具体分享核对文件。记录是本站来源未收录、分享失效、没有目标集、未能核对，还是文件被规则误删。限时或网络错误不是不存在的证据。
